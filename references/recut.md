# recut.md —— 看画面，不看注释

> **什么时候读我**：用户报「XX 秒要删/改」、复用旧切、按上一版重剪、复盘时间轴时。他的秒数指**他看到的成片**，不是脚本注释、不是源片入点。

## 总原则

用户指的是他看到的画面（「天台靠栏杆」「坐在石头上那个延时」），**不是脚本里的注释或上一会话摘要**。

## 报秒数 / 认画面

- 改之前先对 **Discord 成片 `_dc.mp4`** 抽帧。他报「35 秒 / 54 秒」以他看到的为准。`ffmpeg -i FILE -ss T -frames:v 1 out.jpg`（seek 放 input **后面**）才准；clip 时长加总会漂（曾把 54 秒的「某村」算成「某镇」，见 CHANGELOG）。
- 他报的成片秒数区间（「4–8 秒删掉」）：对那个文件抽帧认画面，再 `split_item` / ffmpeg 在这些帧切开删掉。**不要**改成「源片开头只切 1 秒」——他点名的区间可能在口播中段或下一镜走路。
- 同一条镜头中间删一段后，留下的短尾巴会像跳回同一个地方：他说后一个镜头断开、停在前一个结束，就**删掉尾巴**，不要留一两秒同景。
- 删完画面比音乐短：把音乐 `durationFrames` 收到画面终点，否则尾部是黑帧加乐。
- 复用 `editN/NN.mp4` 前**先抽一帧认画面**。编号 ≠ 内容（复用 14.mp4 当「某镇」，文件里是「某村」）。

## 手术式复盘（ffmpeg 线）

- 已有 `editN/00.mp4`… 时：**只重编被改的切**，其余段 concat `-c copy`，再混 BGM。不要从照片 Ken Burns 重跑全片。
- Discord 版对混声后的片**全量编码**（清 DTS）。Non-monotonic DTS 在 copy-concat 时常见，以最终 re-encode 的 `_dc.mp4` 为准。
- 照片+有声混剪用 concat **filter**（同一时钟），不要只靠 demuxer copy。命令见 [ffmpeg-recipes.md](ffmpeg-recipes.md)「concat」。

## 静音动刀前（诊断）

- 报「三十几秒还有噼里啪啦」：对 `_dc.mp4` 抽帧，静**占那几秒的那一切**，不是只静开场后面第一刀。走路镜 `max_volume` 到约 **−4dB** 的尖峰常是麦擦/枝叶噼啪，不是脚步。
- 开场进山 `mean_volume` 很响往往是**他在说话**，不要当杂音整段静掉。
- 他说「照片」可能指成片里看到的**视频段**：先对画面再静音。
- 只静那几切的现场声，BGM 留；本人讲话必须留（政策见 [preferences.md](preferences.md)）。静音做法用 `scripts/mute_segment.sh`。

## 改法先例（他纠正过的）

- 「方向不对，放不进来就别放」：静帧转不正就丢掉，**不要硬 rotate 进片**。
- 「只改点名的那几张」：头顶被裁**不要整片改 letterbox**。铺满裁切是默认；出事的那一两张 `crop` 钉顶（y=0）仍铺满 16:9，不 pad 黑边。
- 「坐在石头上要运镜」：用**成片里原来那张/那镜**，从该镜原片抽静帧再运镜（约 8s）。**禁止另找一张「也像坐着」的顶替**（站在石阶上仰头不是坐）。
- 「大门口自拍」收尾：画面里要有人站在门/殿前。同组最后一张若只有牌匾没人，用对着镜头站着那张；下山切一刀后接这张，不要再叠一段公路。
- 点名一块碑或路名：**在照片里找那个字**再加，不要凭记忆或文件夹名。
- Discord 直接丢照片「加在合适的地方」：拷进项目目录，按地理/叙事插入（石阶→上路后；地面特写→藤/石凳等低视角旁），**不要堆在片尾**。
- 他说后半段照片/视频少：先把 `02_优秀` 静帧文件名对时间线，没进片的下午镜按 4s 插进**下山前**；视频先把已上轨、被裁短的下午 `VID_` 拉回源片里稳的更长一段；源片里下午没有更多 `VID_` 时说清，**不要用上午走路镜充后半**。
- 他说按拍摄时间铺：整条按文件名里的时分秒重排，不留叙事顺序。ChatCut 里删光 V1 再 `alignTo:track-end` 按时间一批批加。
- 同一条 `VID_` 里多切：按**文件名拍摄时间 + 片内秒数**排，不要按「先牌匾后院子」叙事重排。
- 「按旧成片用原片重剪」：镜头表跟上一版，`VID` 换 LRV，**不要借机重做结构**。
- 「不要局限于这个时间」：可超 2–3 分钟默认（上限见 [preferences.md](preferences.md)「时长」）。

## 速度与运镜改法

- 放慢倍率、不插帧：见 [preferences.md](preferences.md)「放慢倍率阶梯」。
- 竖图上摇「太快/突然」：8s + 脚下停 ~0.8s，`crop`+`t`，**不要 `zoompan` 的 `on/d`**（`d` 不是表达式变量）。
- **1080p 不要 zoompan**：小数变焦在高分辨率像整片在晃。升 1080 时旧 720p 脚本里的 `zoompan` 必须丢掉；横图用 `scripts/pan_still.sh`（锁 y 只移 x，余量不够退回 static），或静帧。
- 静帧/运镜做完**抽首帧认人**：中心裁或 zoom 可能落到水缸/地面，人不在就重裁。
- 走路/车载手持仍晃：`deshake` 后 `crop` 回画幅（`rx`/`ry` 必须是 16 的倍数），不要靠 zoompan 假装稳。
