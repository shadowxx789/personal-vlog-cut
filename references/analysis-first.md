# analysis-first.md —— 「先讲分析」与预选

> **什么时候读我**：用户说「读一下…先讲分析」「有什么剪什么」之前的第一步；做预选表、决定哪些照片/视频进片时。

## 流程（只交付判断，不开剪）

用户说「读一下…先讲分析」：**只交付判断，不开剪**。Discord 结论先行。

1. **清单**：照片张数、视频段数/时长、时段（上午/下午是不是两个地）。
2. **看画面**：照片按时段抽代表帧做接触表；能拉下的 `LRV` 抽 1fps。百张级**不要宣称每一张都看过**。
3. **证据盲区**：没看成的长视频写明「证据盲区」，禁止脑补里面有人说话/在走/在山顶。
4. **一天两地**（村 + 古镇）按**两段明信片**，不要硬挪成一座山。

## 02_优秀 / 03_普通 / 00_待删除 规则

- 盘里已有分拣目录时：预选**先吃 `02_优秀`**，缺的主题（定场、人、项目全景）从 `03_普通` 补，`00_待删除` 默认不进。
- 空车/空镜和已有人的同一项目**不要两张都留**。

## 预选表怎么报

- 报时长用**区间**：照片×4–5s + 视频只取**稳的几秒**（不是源片全长）。不要当成片已剪完。
- 目标 ~3 分钟而表估 < ~2:30：补 2–3 张**不重复主题**的照片，**不要用空镜凑秒**。
- 他说「先剪一般看看」（长 LRV 超限读不下来）：用已读照片 + 短段 + 垫乐先交，成片第一句说清哪两段没进，不要卡死等超限文件（下载上限见 [footage-sources.md](footage-sources.md)「夸克」）。
