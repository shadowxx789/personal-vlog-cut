# footage-sources.md —— 等素材、移动硬盘、夸克、LRV/VID

> **什么时候读我**：还没拿到素材、去拿素材（本机移动硬盘 / 夸克）、判断哪段能用时。剪辑命令不在这里。

## 等素材（没素材就停）

- 「就用今天的素材」「有什么剪什么」**≠ 素材已在磁盘上**。
- **没给路径 / 网盘 / 频道里的视频文件**：停。说一句怎么丢，等他丢。
- 不要扫 Downloads / Desktop / Movies / Photos / Discord 历史「猜今天的山」。
- 中途被知会「素材还没给你」：**立刻停搜**，不解释、不补刀。

## 本机移动硬盘探测

- 用户点名移动硬盘上的文件夹：先看 `/Volumes` 已挂上的卷，再对**他说的文件夹名**做精确路径探测（`os.path.exists`）。**不要先 `listdir` 整卷根目录**——大容量卷根目录可能一直卡住，永远到不了目标夹。
- `exists()==True` ≠ 已读素材。必须 `scandir`/`listdir` 真正吐出文件名才能做清单。一次列举卡住：**停**，不要换命令反复打同一块盘；说明证据盲区，让他点开文件夹 / 拷到本机 / 确认能否卸载重挂。

## LRV / VID 规则

- 成片**只从 `VID_*.mp4` 下刀**。**`LRV` 只看内容**（抽帧、认画面），不进片。
- 同一秒 LRV 对上了 ≠ VID 是同一幅（seek 会漂）。抽完段**看 VID 首帧**再 concat，对不上就不要把错段当讲话/远山。4K50 HEVC 的 seek 具体规则见 [ffmpeg-recipes.md](ffmpeg-recipes.md)「4K50 HEVC seek」。
- 手机延时 `VID_*.mp4` 常常只有 ~2 秒 / 60 帧：改前 `ffprobe` duration，别当成长镜头。

## 夸克（加载 `quark-netdisk-ops`）

用户点名网盘文件夹时加载 `quark-netdisk-ops`。

- `search` 文件夹名可能只吐出照片。必须 `browse` 该夹再判断有没有视频。
- 整句文件夹名 `search --search-type dir` 可能 0 条（用户说「甲镇」、盘里是「乙古镇」）。只允许用**日期前缀 `YYYYMMDD`** 再搜 dir；对上近名后**用用户的地名说话**，不要换成文件夹里的写法。
- `download` 单文件上限 **50MB**。大 `VID_*.mp4` 改拉同名 `LRV_*.lrv`（720p，原声还在）。**LRV 也会超限**（60–100MB 已见）——那段就算没看过，**不要重试同一 `download`**。
- 不要拿搜索预览里的十几张 JPG 开剪，更不要据此告诉用户「只有照片」。
- 「先剪一般看看」：超限读不下来的段先跳过，交付时说清（见 [analysis-first.md](analysis-first.md)）。
